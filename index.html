原站 25,000+ 单词已经迁移进来了吗？

已核验原站公开 HTML 的内嵌词库数组，并打包为 25,024 条学习记录（五套考试列表共 25,000 条，另含 100 条精讲词；按原站逻辑替换 76 个重合条目并补入 24 个精讲新词）。首次联网打开时会自动导入本机 IndexedDB；也可下载 JSON 文件，通过“导入词库”手动导入。相同拼写在不同考试列表中保留各自分类。

7 天后会怎样收费？可以取消吗？

正式产品先免费体验 7 天，之后按所选连续包月或连续包年方案自动续费。页面价格由运维配置文件提供，实际扣款金额必须由服务端确认；付款前会明确显示续费日期、金额和取消方式。当前预览只在本设备演示试用计时，不会发起真实扣款。

可以使用微信支付、支付宝，并把收入结算给我吗？

页面已设计微信支付 / 支付宝选择入口，但尚未连接商户。正式接入时需使用你名下的商户账号，服务端创建订单并验签支付回调，收款再按商户平台规则结算到你的账户。支付密钥只放在服务端密钥管理中。

它可以离线使用、添加到主屏幕吗？

已配置 PWA manifest 和 Service Worker 应用外壳缓存；在 HTTPS 部署并由支持的浏览器访问后，可以安装到设备。导入的词库会保存在本机 IndexedDB。首次离线可用内容取决于设备是否已成功缓存应用和词库。

原站的发音、例句和学习进度也能保留吗？

已迁移英 / 美音标、词性、中文释义与考试分类；100 条精讲词还保留例句、翻译、助记、搭配等字段。词库数据本身未内嵌音频文件；原站按需请求 Youdao dictvoice 英 / 美音并在失败时回退系统语音，本 PWA 也采用此方式。公开 HTML 未包含个人学习进度，迁移进度仍需原站账号数据导出。

自动运维目前包含什么？

当前交付包含自动化运营流程设计与前端体验原型。实际定时提醒、扣款、续费失败重试、Webhook 权限同步、服务监控和数据库备份，需部署后端任务、数据库、邮件/通知服务和支付服务商才能真正运行。
