# 原站词库导入

`original-site-wordbank.json` 是从公开原站 HTML 的内嵌 JavaScript 提取并转换的本地词库。具体实现不是调用隐藏下载 API：原站模块脚本用数组 `Qh`、`Vh`、`Zh`、`Kh`、`Jh` 保存五组主词库，并通过 `Yd` 按考试分类映射；每行结构为“word、UK IPA、US IPA、词性、中文释义”。精选词由 `Xp` 汇总，原站函数 `Fh` 将其并入对应列表并去掉重复项。

## 核验结果

- 五个原始列表：高考 3,500、四级 4,500、六级 5,500、考研 5,500、雅思 6,000，合计 25,000 条列表记录。
- 按原站客户端合并逻辑，把 100 条精讲词并入五个列表：76 条替换同列表已有词，另补入 24 条新词，得到 **25,024 条学习记录**。
- 词库按考试分类有大量重叠：25,024 条记录共有 9,103 个不同拼写。应用保留跨考试重复项和各自分类，不把 25,024 条误称为互不重复的拼写数。
- 五个原始数组中 15,871 条含英式音标，12,312 条同时含英美音标；加入 100 条精讲词后，导出包中 15,898 条有英式音标，12,350 条同时有英美音标，24,780 条有词性，全部 25,024 条含中文释义。
- 100 条精讲词包含例句、例句翻译和助记；并保留其近义词、反义词、搭配、词族及出处。词条 JSON 本身没有嵌入音频文件；原站代码按需调用 Youdao dictvoice 英 / 美音端点（type=1 / 2），失败时回退浏览器语音合成。公开 HTML 未包含个人学习进度导出。

## 自动录入

首次联网访问 PWA 时，`index.html` 会读取 `./data/original-site-wordbank.json`，校验记录数并批量写入当前浏览器 IndexedDB。Service Worker 预缓存静态 JSON，导入完成后词库可离线使用。已有非示例词库时不会自动覆盖。

## 手动迁移到另一台设备

在词库区点击“下载词库 JSON”，将文件移到另一台设备，再点击“导入词库”选择该 JSON。导入会替换当前设备的词库；用户的学习进度不随词库文件迁移。

## 数据来源字段

导出文件按原站客户端合并规则整理为 `{ metadata, books }`，每个 book 有独立分类；词条保留 `id`、UK / US 音标、词性、释义和来源分类。精讲词额外保留 `example`、`exampleTranslation`、`mnemonic`、`frequency`、`synonyms`、`antonyms`、`collocations`、`wordFamily`、`examSource` 等字段。
