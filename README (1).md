# Lexio 乐词 · PWA 概念交付

基于你提供的 Lexio 原站模块、内容与配色方向，制作了移动优先的学习落地页和可交互 PWA 原型。当前适合个人体验；真实账号、云端进度同步、订阅扣款和生产后端尚未接入。

## 本地预览

从项目目录通过 HTTP 服务打开（Service Worker 需 HTTPS 或 localhost）：

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

访问 `http://localhost:4173/`。部署时请使用 HTTPS。

## 已交付

- `index.html`：响应式落地页、五类词库筛选与搜索、学习卡片、英美音标、Youdao 按需发音端点及系统语音回退、试用与价格 UI、FAQ 及运维流程演示。
- `manifest.webmanifest`、`sw.js`、图标：PWA 安装与离线缓存。词库首次导入后保存在浏览器 IndexedDB。
- `data/original-site-wordbank.json`：从原站公开 HTML 内嵌数据提取并转换的词库 JSON；共 25,024 条学习记录，包含 100 条精讲词的例句、助记等内容。
- `pricing.config.json`：运营可调试用天数、连续包月 / 连续包年价格与折扣。月价 ¥15、年价 ¥108（40% 折扣）均为可修改示例价。
- `wordbank.config.json`：指向项目内的词库 JSON；首次在线打开自动导入。已有非示例自定义词库时不会自动覆盖。
- `ops/PRODUCTION-OPS.md`、`ops/API-CONTRACT.md`：生产订阅、支付 Webhook、重试、通知、监控与备份方案。

## 原站词库核验与迁移

原站：<https://01a168c5-657e-7ae5-9c33-ae71a4937a8b.arena.site/>

我以浏览器请求头获取原站公开 HTML 后，发现完整词条数组直接内嵌在页面的 module script 中，而非通过公开 JSON API 下载。页面代码把五个数组映射为高考、四级、六级、考研和雅思词库；每条原始记录结构为“单词、英式音标、美式音标、词性、中文释义”。按源代码的合并方式，将 100 条精讲词与词库合并，并从原始列表移除重合项后，得到：

| 词库 | 原始列表条数 | 合并后的学习条数 |
|---|---:|---:|
| 高考 | 3,500 | 3,510 |
| 四级 | 4,500 | 4,503 |
| 六级 | 5,500 | 5,503 |
| 考研 | 5,500 | 5,503 |
| 雅思 | 6,000 | 6,005 |
| **合计** | **25,000** | **25,024** |

25,024 是按考试列表计的学习记录，不是 25,024 个互不重复的拼写：不同考试词库存在重叠，合并后共有 9,103 个不同拼写；同一拼写在不同考试类别中仍分别保留，避免丢失分类和源释义。当前导出中，15,898 条有英式音标、12,350 条同时有英美两套音标、24,780 条有词性；100 条精讲词带例句和记忆助记。词条数据没有内嵌音频文件；原站代码会按需请求 Youdao dictvoice 英 / 美音端点并在失败时使用系统语音。当前 PWA 采用相同的按需音频端点并回退到设备语音合成。公开 HTML 没有个人学习进度导出，个人进度需另行从账号数据迁移。

**录入方式：**首次联网打开 PWA 时，应用会自动读取 `./data/original-site-wordbank.json` 并写入本机 IndexedDB；导入完成后可离线使用。也可在页面点击“下载词库 JSON”，再在另一台设备点击“导入词库”。导入是替换当前词库，不会合并两个来源。若该设备已导入自定义词库，应用不会以原站词库自动覆盖。

## 订阅与支付边界

当前 7 天试用状态只保存在本机，用于原型体验；页面不会发起扣款。微信支付 / 支付宝目前是入口 UI，尚未连接商户、Checkout API 或服务端 Webhook。正式收费必须由后端确认方案、价格、支付结果与订阅权限；不要把支付密钥放入前端或聊天，应使用托管平台 Secret Manager / 环境变量。

`pricing.config.json` 可供运营调整前端展示的月付、年付、试用期及折扣。真实扣款金额仍须由支付服务端独立配置，不能信任浏览器提交的金额。
