## 二、8 项问题的处理

### 1) 视图切换卡顿、掉帧

- 切换时**只对首屏那一个 section 做合成动画**（transform + opacity，210ms），其余板块瞬间切换，不再整页交叉淡入、不再同屏叠 9 个板块。
- 移除了切换期间的 `body { overflow: hidden }`——iOS 上它会把滚动位置归零，看起来就是"跳一下"。现在动画期间照常滚动。
- 进入学习/词库时不再重排整页；首页返回不做长入场动画。

### 2) 点搜索框浏览器自动放大、页面跳动

- 所有文本输入框统一 16px（iOS 小于 16px 会强制放大）：两个搜索框 + 词库直链输入框。
- viewport 保留 `width=device-width`，**没有**禁用用户手势缩放（无障碍要求）。
- 搜索输入 90ms 防抖，输入时不再整表重绘；回车即收键盘。

### 3) 词卡滑动不跟手、误判"已记住"

- 滑动改为单个 `requestAnimationFrame` 写 `transform`，不再每个 touchmove 读写布局。
- **滑动只是切卡**：不标记已掌握，也（本轮修掉的一个真实 bug）**不再把词从"待巩固"队列里删掉**——之前向左滑一次就会静默丢弃一个薄弱词。
- 只有点「记住了 ✓」才计入已掌握。

### 4) 首页改成 App 仪表盘，只显示真实数字

- 手机首屏：固定顶栏 → 标题 → **真实进度卡**（已记住 / 还没记牢 / 今日已学 + 比值条）→ 主按钮 → 6 个功能格。
- 这里修掉一个会让人以为"首页没做"的 CSS bug：隐藏营销插图的 `display:none !important` 同时命中了进度卡（它也是 `.hero-visual`），手机上真实数字**整块是隐藏的**。已改为 `:not(.hero-progress)`，并加了一条测试，逐条求值手机断点里所有 `display:none` 规则，确认不会再命中进度卡。
- 删掉了虚构的"每日 30 词"配额：学习页进度条现在显示**当天真实比例**（记住了 ÷ 当天全部标记），首页统计条同理。

### 5) 误导文案清理

| 原文案 | 现在 |
| --- | --- |
| GitHub 更新词条说明 / GitHub 字样 | 全部移除，词库来源对话框改为通用说明 |
| "DAY 05 自动发邮件提醒" 类运营承诺 | 到期前 14 / 7 / 1 天**打开 App 时本机弹窗**，不承诺邮件、短信 |
| 展示 `pricing.config.json` 来源 | 移除 |
| "后续版本接入"承诺 | 移除；好友对战明确写"本机模拟对手，不是实时在线玩家" |
| "连续学习 7 天 / 本轮计划 30" | 换成真实本机计数与 1,000 条口语句等可核对参数 |
| JS 每次加载都重写价格行为"自动续费" | 已改：明确写"当前版本不扣款"，不再宣称有自动扣费 |
| 套餐功能列表（含"进度同步""词族拓展"） | 只列本版本真实存在的功能 |
| 模拟对手的 "46ms 延迟 / 在线房间" | 改为"本机模拟对手 · 稳扎稳打"，不编造网络数据 |

FAQ 里关于学校/老师的内容改成"**可以提供**的学习跟进与模板服务"，不含任何未经确认的学校、成绩、用户数量。

### 6) 朗读不再夹带中文

- 原本 8,587 条例句是 `The word “X” means “释义” in this context.` 这种中英混排，英文语音会读成乱码。
- 现在 **25,024 条例句 0 条含中文**：Tatoeba 8,898、四六级/考研/雅思词典 14,457、WordNet 693、练习提示句 1,521、学习提示 49。
- 另外把 3,399 条词典残句（`...the president's departure`、`an energetic man`）换成完整句子。
- 仍有 998 条词典只给短语（`a honeymoon suite`）。**不编句子**：卡片标注「词典短语 · 雅思」，整句朗读按钮禁用并给出说明；单词发音仍可用。
- **已安装旧版的用户也会被修好**：词库存在 IndexedDB，只有内容迁移能把修复送进去。原逻辑只在 `dictionary:*` 覆盖 `generated-*` 时替换，且版本号没升，导致老用户永远拿不到新例句。现改为：含中文的例句、词典残句都会被替换，版本号升到 `example-full-sentences-2026-11-v3`，服务端 SW 对 `data/*.json` 改为**网络优先**（离线仍有缓存），否则预缓存会把老数据一直喂给迁移。

### 7) 安装引导（含视频）

- 右上角「安装」→ 打开引导弹窗，内含 12 秒竖屏安装示意视频（`media/install-guide.mp4`，720×1280，H.264，383 KB，静音），带封面图、`playsinline`、关闭即暂停。
- 视频下方是安卓 Chrome / iPhone Safari 的手动步骤；支持 `beforeinstallprompt` 时「立即安装」直接调用原生安装，不支持时给出说明。

### 8) 随机例句 / 好友对战入口可用

- 「随机看一条例句」：从**真的有例句**的词里随机抽一条，跳到学习视图并翻到卡片背面。
- 「游戏化闯关 / 好友对战」：直接进入学习视图的对战面板并开始匹配，本机模拟对手，10 题词义快答，答错自动进复习队列。
- 顺带修了两处记录错误：点「记住了」今日计数会 +2（按钮和 `markMastered` 各记一次），现已只记一次；首页「看待巩固词」按钮此前没有绑定，现已接到记忆面板。

## 四、必须在真机上确认的部分

沙箱里没有可运行的浏览器（见第五节），下面这些只能由你在手机上确认。建议按顺序试：

1. **首页是否填满一屏**：iPhone Safari 打开线上地址，首页应"顶栏 + 标题 + 真实数字卡 + 两个主按钮 + 4~6 个功能格"，底部不被空白带占据；iOS 底部安全区不应压住内容。
2. **切换是否还卡**：首页 ↔ 学习 ↔ 词库来回点 10 次。应为 210ms 的轻推移/淡入，无整页闪烁、无滚动位置跳动。
3. **点搜索框是否放大**：在词库搜索框、口语句搜索框点一下。页面**不应**自动放大；键盘弹起时布局不应错位。
4. **滑动是否跟手**：学习页左右滑词卡。卡片应跟着手指走、松手落位；滑完**不能**出现在"已记住"里，也不能把词从"待巩固"里删掉。
5. **朗读**：点「🔊 朗读例句」，应只读英文整句，没有中文或"引号乱码"；iOS 若第一次没声音，再点一次（代码里已有 iOS 手势容错）。遇到「词典短语」的卡片，整句朗读按钮是灰的，属预期。
6. **安装**：点右上角「安装」，视频能播放、关闭后自动暂停；按步骤添加到主屏后，从图标打开应为全屏无地址栏。
7. **两个入口**：点「随机看一条例句」应翻到背面；点「游戏化闯关」应直接开始匹配并进入 10 题。
8. **提醒**：不想等就别测；要测可在控制台执行
   `localStorage.setItem('lexio.demoTrialStarted', String(Date.now()-6*86400000-3600000)); localStorage.removeItem('lexio.reminderShown'); location.reload()`
   应弹"还有 1 天到期"，且当天重复打开不再弹。

> 提醒：**已安装过旧版的手机**需要联网打开一次，等 Service Worker 更新（会自动刷新一次）后，词库例句才会更新为纯英文版本。
