# 乐词声音档案

| 用途 | 当前发布设置 |
| --- | --- |
| 读单词 | 默认美音 `en-US`，可切换英音 `en-GB`。优先词条 `us` / `uk` 录音，否则使用有道词典 `dictvoice`，美音 `type=2`、英音 `type=1`，播放速度 1×。词典服务没有公开可复用的说话人 ID，不能将它记作某位固定配音员。单词无法播放录音时会尝试设备同语种的声音，受设备影响。 |
| 读句子 | **Arena 对话中已选 `voice-00`**，美式英语 `en-US`，1×。已有 MP3 为音色参考（例：`card-1.mp3`、`daily-1.mp3`）。该 ID 属于原会话，不是可在任意语音服务使用的模型名称。只按完整英文匹配录音，无录音时保留文字，不切换系统声音。 |

当前 3,792 段不同文本的录音，覆盖 11 个场景全部 1,100 条日常与商务口语，以及部分词卡例句。每条口语均对应完整的本地 MP3，点击即可播放，无需等离线包准备完成。

口语扩充批 989 条：89 条商务表达为连续录制后按原文对齐切分；900 条句型练习中 200 条整句录制，700 条用同一 `voice-00` 的句型前半句和任务短语组合（保留陈述/疑问语调，切口淡入淡出），不是设备合成，也不是换另一个人读。严格按原英文建立映射，重复的英文共享录音。

核对范围为内置词库、演示词卡、日常及商务口语，按程序当前可朗读的文本规则剔除词典残句、去重；不包含用户外部导入的词库。

从 `lexio-pwa-full/` 运行：

```
node scripts/voice-queue.mjs                      # 实时统计
node scripts/voice-queue.mjs --pending > /tmp/pending.jsonl  # 每行给出原文、来源、建议文件名
```

后续录制必须沿用同一个已选声音；生成实际 MP3 后，再登记到 `index.html` 的 `selectedRecordings` 和 `sw.js` 的 `bulkAssets`。不要把未生成的文件登记成可播放。`npm test` 校验录音、离线清单和媒体范围请求。

词卡批次进度、续录和交接：[VOICE-HANDOFF.md](../../VOICE-HANDOFF.md)。
