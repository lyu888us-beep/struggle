核对范围为内置词库、演示词卡、日常及商务口语，按程序当前可朗读的文本规则剔除词典残句、去重；不包含用户外部导入的词库。

从 `lexio-pwa-full/` 运行：

```
node scripts/voice-queue.mjs                      # 实时统计
node scripts/voice-queue.mjs --pending > /tmp/pending.jsonl  # 每行给出原文、来源、建议文件名
```

后续录制必须沿用同一个已选声音；生成实际 MP3 后，再登记到 `index.html` 的 `selectedRecordings`（单词样音用 `selectedWordRecordings`）和 `sw.js` 的 `bulkAssets`。不要把未生成或未安全切片的文件登记成可播放。`npm test` 校验录音、离线清单和媒体范围请求。
