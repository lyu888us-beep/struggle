# 乐词声音档案

| 用途 | 当前发布设置 |
| --- | --- |
| 读单词 | 当前有 **1,343 个本地单词音频**（清单：`word-audio-manifest.json`），美音 `en-US` 优先播放 `voice-00` MP3。五个样音由用户试听认可；其余 1,338 个经自动对齐，尚未逐条人工听检。未录单词仍不读取词条自带的 `us` 录音：iPhone/iPad Safari 在点击手势内先请求有道 `dictvoice type=2`；若远程媒体失败或超时，改用系统 `en-US` 语音。其他设备优先使用浏览器语音合成，并在当前页面会话内锁定一个可用的美式音色。系统语音跨设备不保证同一说话人。英音 `en-GB` 仍优先词条 `uk` 录音，否则使用有道 `dictvoice type=1`；失败后使用设备英音。语速均为 1×。 |
| 读句子 | **Arena 对话中已选 `voice-00`**，美式英语 `en-US`，1×。已有 MP3 为音色参考（例：`card-1.mp3`、`daily-1.mp3`）。该 ID 属于原会话，不是可在任意语音服务使用的模型名称。只按完整英文匹配录音，无录音时保留文字，不切换系统声音。 |

当前 `media/voice/` 共 **19,387 个 MP3 文件**（原有 17,569 个 + 累计新增 1,818 个）。累计新增包含 472 个缺录词典短语、3 个精确改写例句、5 个用户确认样音和 1,338 个队列单词音频。所选语音离线清单同步包含已发布文件。

词库中有 28,414 条内置词条；当前 `.tmp-voice/words-unique.json` 只包含 9,830 条唯一词条队列，不能据此宣称 20,000+ 全库音频已完成。该队列已有 1,343 条本地逐词录音，另有 8,487 条未录。

## 批量单词录音状态

- 词条清单 `word-audio-manifest.json` 记录全部 1,343 个已发布单词映射。
- 最近 10 个 `voice-00 / en-US` 合并源音频覆盖了 1,423 条尚未录制的队列项；PocketSphinx 对齐后，用保守的静音切点检查切出 **1,328 个**独立词条 MP3：源组 0、1、3 安全切出 403 个；源组 2、4–9 从其余可安全分段处再切出 925 个。已发布逐词 MP3，不是临时长录音。
- 这 10 组中仍有 **95 条**因邻接词之间没有可靠静音切点而被跳过，未强行切开、未加入映射、未发布。10 个合并源音频在 `.tmp-voice/words/next-batch-002/`，安全切片和跳过报告在 `.tmp-voice/words/aligned-next-batch-002-partial/` 与 `.tmp-voice/words/next-batch-002/partial-safe-report.json`。合并源音频不算独立词条 MP3。
- 这证明可将逐词 TTS 调用改为每段约百余条的合并音频；实际产量仍受安全切点影响，不能把源文本数或 TTS 段数当成已发布成品数。
- 本地离线缓存版本 `lexio-shell-v119-word-audio-batch-003`。JSDOM 自动测试模拟 iOS 远程媒体失败后转用系统 `en-US` 的路径；这不是 iPhone 16 Pro Max／iOS 27 真机验证。

原有录音覆盖 11 个场景全部 1,100 条日常与商务口语，以及部分词卡例句；每条口语都对应本地完整 MP3。口语扩充批 989 条：89 条商务表达为连续录制后按原文对齐切分；900 条句型练习中 200 条整句录制，700 条用同一 `voice-00` 的句型前半句和任务短语组合（保留陈述／疑问语调，切口淡入淡出），不是设备合成，也不是换另一个人读。严格按原英文建立映射，重复的英文共享录音。

核对范围为内置词库、演示词卡、日常及商务口语，按程序当前可朗读的文本规则剔除词典残句、去重；不包含用户外部导入的词库。

从 `lexio-pwa-full/` 运行：

```
node scripts/voice-queue.mjs                      # 实时统计
node scripts/voice-queue.mjs --pending > /tmp/pending.jsonl  # 每行给出原文、来源、建议文件名
```

后续录制必须沿用同一个已选声音；生成实际 MP3 后，再登记到 `index.html` 的 `selectedRecordings`（单词样音用 `selectedWordRecordings`）和 `sw.js` 的 `bulkAssets`。不要把未生成或未安全切片的文件登记成可播放。`npm test` 校验录音、离线清单和媒体范围请求。
