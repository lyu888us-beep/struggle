# 乐词声音档案

| 用途 | 当前发布设置 |
| --- | --- |
| 读单词 | 当前有 **8,681 个本地单词音频**（清单：`word-audio-manifest.json`），美音 `en-US` 优先播放 `voice-00` MP3。五个原始样音由用户试听认可；其余 8,676 个队列词音频经自动对齐/安全切片，尚未逐条人工听检。未录单词不读取词条自带的 `us` 音频：iPhone/iPad Safari 在线时在点击手势内请求有道 `dictvoice type=2`，失败或超时后使用设备 `en-US` 语音；若浏览器报告离线则立即使用设备语音。其他设备优先使用浏览器语音合成，失败时回退有道，并在当前页面会话内锁定可用音色。系统语音跨设备不保证同一说话人。英音 `en-GB` 仍优先词条 `uk` 录音，否则使用有道 `dictvoice type=1`；失败后使用设备英音。语速均为 1×。已映射的 `voice-00` 单词录音若不能播放，不会伪装成另一音色。 |
| 读句子 | 已有完整句子优先播放精确文本对应的本地 MP3；未录制的完整英文句子，或录音无法启动时，使用设备 `en-US` 语音兜底，并在按钮上注明它不是 `voice-00`。未录的词典片段仍不伪装成整句；语音生成审核阻止的文本及其嵌入句也不走系统合成回退。设备语音不是所选声音的录音，且跨设备声音可能不同。 |

当前 `media/voice/` 共 **26,735 个 MP3 文件**（原有 17,569 个 + 累计新增 9,166 个）。累计新增包含 472 个缺录词典短语、13 个准确映射的词库例句录音（其中 10 条来自本轮安全补录）、5 个用户确认样音，以及 8,676 个队列单词音频。每次点播的音频会缓存；启动时只优先准备当前及接下来 20 张词卡的单词/例句录音。全库离线缓存改为用户主动点击，并显示进度；安装时不再预下载较大的安装引导视频。兼容缓存仍使用 v124 命名，以保留现有用户已下载的音频。

词库中有 28,414 条内置词条；当前 `.tmp-voice/words-unique.json` 只包含 9,830 条唯一词条队列，不能据此宣称 20,000+ 全库音频已完成。该队列已有 8,681 条本地逐词录音，另有 1,149 条未录。

核对范围为内置词库、演示词卡、日常及商务口语，按程序当前可朗读的文本规则剔除词典残句、去重；不包含用户外部导入的词库。

从 `lexio-pwa-full/` 运行：

```
node scripts/voice-queue.mjs                      # 实时统计
node scripts/voice-queue.mjs --pending > /tmp/pending.jsonl  # 每行给出原文、来源、建议文件名
```

队列完整性脚本分别统计完整可朗读文本与词典短语，并逐条检查现有映射的 MP3 文件。本轮部署 10 条通过自动对齐与解码检查的完整例句后，当前 **488 个完整句子待补**；另有 **1 个被审核阻止的词典短语**单独保留、不进入完整句子队列；现有 17,556 个录音映射均能找到对应文件。`--pending` 只输出完整文本，不会把短语伪装成句子。

后续录制必须沿用同一个已选声音；生成实际 MP3 后，再登记到 `index.html` 的 `selectedRecordings`（单词样音用 `selectedWordRecordings`）和 `sw.js` 的 `bulkAssets`。不要把未生成或未安全切片的文件登记成可播放。`npm test` 校验录音、离线清单和媒体范围请求。
