# 词库数据与例句/记忆线索来源

`original-site-wordbank.json` 是从原站公开词库整理得到的五类学习记录。相同拼写在不同考试分类中分别保留，共 25,024 条记录。

## 例句与记忆线索覆盖

本次补充仅填空字段，并为数据逐条保留来源标记：

- 16,315 条空缺例句从项目内 `premium-english-learning-landing-page (1).zip` 的 IELTS、考研、CET-4、CET-6 原始词典数据按词头匹配取得；1,091 条原有精讲例句保留原样。原始句子及其对应译文不会被自动改写。
- 9,071 条空缺记忆法从上述词典的 `remMethod` 字段按词头匹配取得；原有精讲记忆线索保留原样。
- 仍无可信原句的 8,609 条记录使用了**明确标记的释义提示**（不是自然语境例句，也不应被当作真实语料）；没有可用词典记忆法的记录使用通用主动回忆提示（不是词源/词根记忆法）。这两类生成内容分别以 `exampleSource: "generated-gloss-prompt"` 和 `mnemonicSource: "generated-recall-cue"` 标记，界面会明确标注。
- 每条 `example`、`exampleTranslation`、`mnemonic` 字段均有内容，但这不代表 25,024 条都拥有真实语料例句或专家编写的助记。高考列表没有找到相同格式的独立详细词典源，精确匹配到的跨考试词头才使用词典资料。

可用 `python3 scripts/enrich_wordbank.py` 重跑词库补充脚本；它以词头规范化后精确匹配，只填空字段，并输出来源计数。

## 本地保存与更新

首次联网启动会把内置词库保存到 IndexedDB。此版本会对已有的内置词库做一次只补空缺字段的迁移：保留用户现有词条、释义与已有例句/助记，不会重置学习进度或扩删词条；迁移版本记录在本机数据库元数据中。Service Worker 更新后会载入新词库资源。

联网同步仍可从 GitHub Raw JSON / CSV 更新本机词库；同步操作是完整词库替换，与自动补齐不同。学习进度独立保存在本机。

## 日常口语句库

`daily-conversation.json` 是随 PWA 一起发布并由 Service Worker 预缓存的本地场景表达集，共 1,000 条，覆盖日常交流、餐饮、购物、交通、酒店、机场/出差、医疗药房、工作沟通、电话预约与紧急求助，每类 100 条。数据保留原有 100 条，并补充 900 条按场景任务搭配常见句型组合的练习表达；英文及中文由本项目整理编写，未标称来自外部网站。医疗句仅供语言练习，不构成医疗建议。
