# Lexio 乐词 · 全功能版 PWA

手机优先的单页 PWA。学习、词库、订阅使用独立视图与页面转场。五类考试词库共 25,024 条记录，另有本地缓存的 1,000 条日常场景口语表达。学习位置与进度保存在本机；重开时自动回到最近学习卡。

> 好友对战与订阅结账目前是产品演示逻辑。对战为本地模拟，并非真实在线匹配或联网房间。

## 部署与手机安装

将本目录内容部署到支持 HTTPS 的静态托管。若 GitHub Pages 发布的是仓库根目录，本 PWA 位于 `https://lyu888us-beep.github.io/struggle/lexio-pwa-full/`。用 iPhone Safari 打开部署后的 HTTPS 地址，再选择「分享」→「添加到主屏幕」。首次联网启动并缓存词库后，可离线学习。

## 词库更新

- 内置词库自动载入；没有手动文件导入入口。
- 词库页的「联网同步」仍可使用 GitHub Raw JSON / CSV 链接更新本机词库。
- 例句与记忆线索存在真实词典来源和通用生成提示两种类型，字段来源及界面标签会区分；并非所有词条都有真实语料例句或专门编写的助记。详见 `data/README.md`。

## 语音与对战

- 单词发音使用所选英式 / 美式发音。
- 例句点击后直接调用设备的 `en-US` 系统语音完整朗读，避免逐词网络请求造成 iOS Safari 用户手势失效。自动化测试只验证已发起系统语音调用；仍不能代替 iPhone/Safari 真机扬声器测试，也无法排除静音、系统语音设置或设备路由问题。
- 每局本地模拟对战生成并逐题呈现 10 道题，完成第 10 题后结算。自动化交互测试核对了答题计数 10/10；不是实际联网对战服务。

## 2026-11 应用外壳更新

- 视图切换只对一个首屏板块做 GPU 合成动画（210ms），首页不再拼装长动画，返回首页不再掉帧。
- 首页改为填满屏幕的 App 外壳：固定顶栏 + 底部标签栏 + 真实本机进度卡（已记住 / 没记牢 / 今日已学）。
- 词库搜索框统一 16px 字号，iOS/Android 聚焦时不再自动放大。
- 单词卡滑动改为单一 `requestAnimationFrame` 写 transform，不再逐事件读写布局；滑动只换卡，不再冒充“已记住”。
- 顶部“安装”按钮打开安装引导弹窗，内含 12 秒安装示意视频 `media/install-guide.mp4`（可选 `media/install-guide-poster.jpg` 封面）。
- “例句来源”按钮随机打开一张带例句的词卡背面；“游戏化闯关”“好友对战”直接进入 10 题对战面板。
- 记忆引擎与首页进度都读取 `lexio.masteredWords` / `lexio.weakWords` / `lexio.studyHistory`，只显示本机真实记录。
- 到期提醒改为到期前 14 / 7 / 1 天打开 App 时的本机弹窗；不再有“DAY 05 自动发邮件”这类宣传。
- 宣传页删除 GitHub 更新词条说明、团队版接入说法、价格来源说明与虚构成绩/评价；老师与学校合作改为“可以提供的服务”表述。
- 词库基础数据：8,587 条夹带中文的“例句”已全部替换为纯英文；另有 3,399 条词典残句（如 `...the president's departure`）换成完整句子。现在 8,898 条来自 Tatoeba、14,457 条来自四六级/考研/雅思词典、693 条来自 WordNet，1,521 条为明确标注的英文练习提示句。
- 仍有 998 条词典只提供短语（如 `a honeymoon suite`）。App 内标注为「词典短语」，不伪装成句子、不提供整句朗读——没有可信来源时不会自己编句子。
- 已安装旧版本的用户会在下一次联网打开时自动迁移词库内容（`BUNDLED_CONTENT_VERSION = example-full-sentences-2026-11-v3`）。

运行测试：`npm test`（jsdom 导航/语音/进度/提醒/文案断言）。
